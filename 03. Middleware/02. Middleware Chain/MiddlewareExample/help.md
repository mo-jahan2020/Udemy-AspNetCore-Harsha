در این مثال، دو middleware اول باید کارشان را انجام دهند 
(Hello و World ) و سپس اجازه دهند بقیه‌ی زنجیره ادامه پیدا کند.
برای همین از Use استفاده شده که next دارد.
اگر آن‌ها را Run می‌کردیم، next وجود نداشت و زنجیره بعد از اولین Run قطع می‌شد؛
آن‌وقت فقط Hello چاپ می‌شد و World Ali11 هرگز اجرا نمی‌شدند.

به بیان ساده:

Use = «کاری بکن، بعد بگذار ادامه پیدا کند» (میانی)
Run = «اینجا نقطه‌ی پایان است» (انتهایی)
